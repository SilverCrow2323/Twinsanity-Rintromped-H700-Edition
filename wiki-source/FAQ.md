# FAQ

## Is the H700 / MuOS build playable?

Not yet confirmed. The current preflight package is diagnostic and does not establish that the game reaches the title screen or runs correctly on a physical handheld. Check the latest [H700 / MuOS port status](H700-port-status).

## Which device and firmware are supported?

The player target is an Allwinner H700 handheld running MuOS. Every accepted release must name the exact tested handheld model and MuOS version. Do not assume that every H700 device or firmware revision behaves identically.

## Can I install the diagnostic .muxapp to play?

No. It is a diagnostic package for graphics and display checks, not a game release.

## Does the project include Crash Twinsanity game data?

No. You must supply your own legally obtained disc image. Never upload it to issues, pull requests or public file shares.

## Where are saves and settings stored?

The exact paths must be documented by the validated MuOS package. Until those paths are confirmed on hardware, back up your card and do not assume locations from another target.

## Where should I report a problem?

Open a repository issue with the handheld model, MuOS version, package checksum, exact reproduction steps and relevant logs. Do not attach copyrighted game data.
