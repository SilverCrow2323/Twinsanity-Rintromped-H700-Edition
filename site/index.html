01 / What you're running

One game folder.
One clear workflow.

The launcher installs the finished application and keeps its settings, memory cards and mods together. No game data is distributed in release archives.

Engine

NativeEE

The decompilation is built for the target platform through a narrow platform seam. Desktop and Vita builds use their respective native lanes.

Install & manage

03 / First launch

Know where your files go.

The install is deliberately self-contained: the game folder is the place to look first when backing up, moving or removing an installation.

Launcher / Games

Your installed games

Use the Games page to manage the installed game and start it.

Default data layout

  • disc-image.txt remembers the selected disc image.
  • userdata/ stores settings and memory cards beside the game.
  • An existing ~/.twinsanityevolved installation may continue to be used.
  • Removing the self-contained game folder removes the data stored inside it.
Keep your own backups of memory cards and settings before replacing or deleting an installation.
04 / Configuration

Make the game behave.

Most player-facing options live in the game's Options menu. Advanced launch settings can also be stored in userdata/ps2r.ini.

Launcher / Settings

Launcher preferences

Review the configured paths and platform-specific settings.

PAL timing

50 Hz game rate

Open Options → graphic options → game rate and choose 50 hz (pal). It takes effect after restarting the game. The same setting is game.hz = 50 in userdata/ps2r.ini; --hz 50 applies it for one run.

Disc pacing

Console-paced loading

Set disc.speed = console in userdata/ps2r.ini, or launch with --disc-speed console, to preserve console-paced disc reads during loading.

07 / Troubleshooting

Fix the cause,
not the symptom.

Start with the install folder and the exact error. Include platform, architecture, release version and relevant logs when asking for help.

Image not recognised

Confirm the disc region and revision. The known supported images are PAL SLES-52568 and North American SLUS-20909 v2.00.

Patch refused

Check that the patch targets your exact base image and region. A patch for a different revision is not interchangeable.

Settings seem lost

Check whether the launcher is using the self-contained userdata/ folder or an earlier ~/.twinsanityevolved directory.

Slow or uneven play

Record the platform, build, game rate and relevant graphics settings. PAL timing can be set to 50 Hz where appropriate.

Launcher update issue

Use the official release archive and review the launcher's Games page. Avoid mixing support files from different releases.

Still stuck?

Open a repository issue with reproduction steps, logs and screenshots. Never attach copyrighted game images or game data.
